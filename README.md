# 智信芸豆 YDwork

> 懂业务、提效率、伴组织进化的 AI 伙伴

YDwork（智信芸豆）是一套支持**私有化部署**的企业级 AI 助手平台：把大模型能力装进组织自己的服务器，围绕专家、技能、知识库与连接器，为业务部门和信息系统部门提供开箱即用的智能工作台。

## 核心能力

- 🤖 **多智能体（Agent）工作台** —— 按岗位与业务场景创建专属智能体，配备独立知识库、技能与记忆，支持会话、任务与文件协作
- 📚 **知识库与检索增强（RAG）** —— 文档上传、向量化检索、引用溯源，让 AI 回答有据可依
- 🧩 **技能（Skills）体系** —— 结构化能力包按需安装/启停，内置技能随平台分发，可对接企业自建技能市场
- 🔗 **连接器与渠道接入** —— 对接企业微信等 IM 渠道与外部服务，AI 助手直达员工工作入口
- ☁️ **云端协同（Bridge）** —— 跨设备远程协同与浏览器流控制，支持按用户/角色授权
- 🛡️ **权限与审计** —— 目录级权限管控（RBAC）、登录锁定保护、操作审计留痕
- 📦 **数据私有化** —— 数据落盘本地（SQLite + bind mount），支持自动备份与恢复

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python 3.12 · FastAPI · SQLite |
| 前端 | React · Vite（SPA，PWA 离线支持） |
| 部署 | Docker / Docker Compose |
| AI | 多模型接入（LLM / 语音 / 嵌入模型） |

## 快速开始

```bash
# 1. 准备 docker-compose.yml 后启动
docker compose up -d

# 2. 查看运行状态
docker compose ps
curl http://localhost:8088/api/health
```

首次启动后使用向导完成管理员初始化，随后在「设置 → 用户」中创建账号、分配权限。
